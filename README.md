# X5 App Analytics

Отдельный дашборд развития мобильного приложения X5. Это не CRM для ботов.

## Что показывает

- скачивания и установки App Store / Google Play;
- покупки, выручку, подписки и возвраты;
- динамику по дням и агрегированную воронку;
- страны и доли платформ;
- последние опубликованные сборки.

Apple и Google не раскрывают личность человека, который просто скачал приложение. Публичный дашборд содержит только агрегированные показатели и не публикует пользователей или платёжные идентификаторы.

## Запуск

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

Production собирается Vite и публикуется через GitHub Pages.
